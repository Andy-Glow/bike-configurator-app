# VELOSIPED STUDIO

Интерактивный 3D-конфигуратор велосипедов с полноценной e-commerce логикой. Проект объединяет современный UI/UX дизайн, сложную 3D-механику и производительную архитектуру на базе React Three Fiber.

**[Ссылка на живое демо проекта](https://andy-glow.github.io/bike-configurator-app)**

---

## Ключевые особенности

- **Интерактивный 3D-конфигуратор**: Полноценная настройка велосипеда в реальном времени — смена цвета рамы и включение/выключение аксессуаров (крылья, багажник, корзина).
- **Динамическая загрузка моделей**: Каждая карточка товара подгружает свой уникальный `.glb` файл с автоматическим центрированием и адаптивным масштабированием (без «прыжков» и сломанных пивотов).
- **Продвинутый UX**: Управление 3D-камерой (вращение, зум кнопками и колесиком) и эффектные переходы между страницами (View Transitions API).
- **Каталог с фильтрами**: Поиск по названию и фильтрация по типам велосипедов (городские, горные, шоссейные).
- **E-commerce логика**: Рабочая корзина с подсчетом итоговой стоимости, избранное с сохранением состояния и бутафорская модалка авторизации.
- **Адаптивность**: Полностью переработанный интерфейс для мобильных устройств (выезжающие шторки, фиксированные кнопки, скрытие второстепенных элементов).
- **Стиль «Жидкое стекло»**: Повсеместное использование Glassmorphism (размытие фона, полупрозрачные границы) и неоновых акцентов.

---

## Стек технологий

- **Framework**: Next.js 15+ (App Router), React 19
- **3D & WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **State Management**: Zustand (корзина, избранное, конфигуратор, авторизация)
- **Анимации**: Motion (Framer Motion)
- **Стилизация**: SCSS Modules, CSS-переменные
- **Язык**: TypeScript
- **Сборка**: Turbopack

## Структура проекта

```text
src/
├── app/                  # Страницы Next.js (Главная, Конфигуратор, Layout)
├── components/
│   ├── auth/             # Модальное окно входа
│   ├── cart/             # Корзина и модалка успешного заказа
│   ├── catalog/          # Сетка товаров, карточки, фильтры
│   ├── configurator/     # Панель настроек (цвета, аксессуары) и зум
│   ├── favorites/        # Шторка избранного и кнопка-сердечко
│   ├── layout/           # Шапка сайта (Header)
│   ├── scene/            # Все 3D-компоненты (Canvas, BikeModel, обертки)
│   └── ui/               # Базовые элементы (Иконки, ScrollReset)
├── data/                 # Моковые данные (конфигурации велосипедов)
├── hooks/                # Кастомные хуки (логика зума)
├── store/                # Глобальные стейты Zustand
├── styles/               # Глобальные SCSS переменные и миксины
└── types/                # TypeScript интерфейсы
```
